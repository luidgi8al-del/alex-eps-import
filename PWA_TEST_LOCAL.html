Test local de la PWA

Cette page active le mode PWA uniquement sur l'adresse locale de ton ordinateur.

Préparation du mode hors connexion…
  1. Attends que le message vert apparaisse.
  2. Ouvre ensuite le site local.
  3. Dans Edge ou Chrome, utilise l'icône d'installation située dans la barre d'adresse.
  4. Après une première ouverture connectée, coupe Internet puis relance l'application installée.
