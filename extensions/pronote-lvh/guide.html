Transfert EPS vers PRONOTE Internet

Version d’essai 0.1. Le connecteur a été testé sur un tableau simulé. La compatibilité avec le tableau réel de PRONOTE reste à vérifier. Un tableau non reconnu bloque le remplissage.

Installer sur Chrome, sur ordinateur

  1. Téléchargez l’archive depuis l’écran d’export de l’évaluation EPS et décompressez-la dans un dossier permanent.
  2. Ouvrez chrome://extensions, activez le mode développeur et choisissez « Charger l’extension non empaquetée ».
  3. Sélectionnez le dossier contenant manifest.json. Épinglez « EPS LVH — Transfert PRONOTE » dans la barre de Chrome.

Préparer le transfert

  1. Dans une évaluation EPS, choisissez « Exporter vers PRONOTE », puis « Préparer pour PRONOTE Internet ».
  2. Connectez-vous normalement au PRONOTE du lycée Victor Hugo. Ouvrez la bonne classe et le devoir voulu.
  3. Ouvrez l’extension et collez le transfert dans sa zone de texte. Cliquez sur « Vérifier sur cet onglet PRONOTE ».
  4. Choisissez la colonne du devoir en cliquant sur une cellule. Vérifiez l’aperçu nominatif, la classe, le devoir et le barème.
  5. Le bouton de remplissage devient disponible uniquement si toutes les correspondances sont uniques et les cellules reconnues. Les notes existantes sont conservées et les valeurs non renseignées sont ignorées.
  6. Après remplissage, contrôlez puis rouvrez le devoir dans PRONOTE pour vérifier sa sauvegarde. Le connecteur ne confirme pas l’enregistrement sur le serveur.

Dans l’application Android

Ouvrez une évaluation puis « PRONOTE Internet · essai ». Connectez-vous dans la fenêtre intégrée, ouvrez le devoir et choisissez « Vérifier le transfert ». Le même aperçu s’affiche. Si la connexion intégrée est refusée par PRONOTE ou l’ENT, utilisez le parcours ordinateur.

Données et limites

Le connecteur ne possède ni accès aux cookies ni service serveur. Il n’enregistre pas vos identifiants ou les notes. Chrome lui donne accès à l’onglet actif lorsque vous le lancez. Seul le domaine PRONOTE du lycée est accepté. Le transfert reste dans le presse-papiers jusqu’à sa prochaine modification.

Les homonymes, les élèves manquants, les tableaux partiellement affichés et les éditeurs non reconnus arrêtent la préparation. Ne pas utiliser pour une classe réelle avant validation sur un devoir d’essai. Fermez le panneau pour supprimer son aperçu.
